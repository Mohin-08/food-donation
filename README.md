# food-donation

This repository is organized as a simple monorepo:

- `food-expresso/` - Frontend (React + Vite)
- `backend/` - Backend (Spring Boot)

## Run Frontend

```bash
cd food-expresso
npm install
npm run dev
```

## Run Backend

```bash
cd backend
./mvnw spring-boot:run
```

On Windows PowerShell:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```
